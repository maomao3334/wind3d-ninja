# Wind3D 1.1.9

统一的 Windows 风场与湍流软件。安装后启动 `Wind3D.exe`，在同一界面切换四个模式：

| 模式 | 功能 |
|---|---|
| 常规风场 | WindMaster、DAT、UAV、通用站点导入，按时间、高度和分辨率输出 NetCDF/KMZ |
| 湍流 RANS | 逐站垂直剖面背景与 UAV 独立验证；也可手动指定背景风，无需站点观测 |
| 逐站观测同化 | 对 RANS 背景作逐站最优插值分析，保留背景与分析结果 |
| 原生 RANS 耦合同化 | 站点局部源项直接进入 Windows 原生 U/k/epsilon 方程，输出真实求解场与独立验证 |

双击 `Wind3D-Ninja-Setup-1.1.9.exe` 安装。软件已包含 Python、Qt、WindNinja 3.12.2 和原生 OpenFOAM 运行库，无需 WSL/Linux 环境。离线计算需选择本地 DEM。迁移便携版本时复制整个 `Wind3D` 文件夹。

## 已知限制：现场风向精度未通过验收

Windows 安装、运行和输出文件检查通过，不代表现场风向精度合格。在 UTC `2024-04-03T08:06:00Z`、50 m 高度、200 m 网格的既有验证中，风向圆周 MAE 为 **103.384928°**；同化前为 **103.410125°**，尚未显示明显改善。844 条记录中仅 30 条通过当前时间和高度筛选，对应 11 个不同 XYZ 位置。

仪器方向基准、运动补偿、偏角应用、对时及高度基准尚缺当次观测的独立依据，不能认定是原始数据错误，也不能排除软件输入解释或模型误差。合成固定站仅用于机制测试，不是现场校准真值；103° 是平均绝对角误差，不能作为固定偏角直接扣除。详见[风向精度限制](docs/wind_direction_calibration.md)和[1.1.9 验证范围](packaging/validation-v1.1.9.md)。

## 使用与文档

首页按所选模式提供“选择数据 → 确认时间 → 确认高度与风向 → 设置输出”的分步流程，手动背景风自动跳过观测校准。第二页是高级设置；第三页“使用方法”先解释模式用途，再介绍材料、操作和结果。

扫描输入数据后，可分别选择 UAV 和雷达的时间字段、来源时区，并预览原始时间与转换后的 UTC 范围；UAV 支持设备取样时间和 PC 采集时间。确认时间范围重叠后再选择模拟时刻，计算与独立验证使用同一时间配置。
